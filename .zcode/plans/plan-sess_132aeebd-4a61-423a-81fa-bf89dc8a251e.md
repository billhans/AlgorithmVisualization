## 核心可视化要素
1. **两个 DP 表格同步**：因为一维/二维的外层(i)和内层(j)遍历节奏相同，可同步步进，每步都是"处理物品 i、容量 j"。
2. **颜色高亮系统**（教学关键）：
   - 🟣 紫色 = 当前正在更新的格子 `dp[i][j]` / `dp[j]`
   - 🟠 橙色 = 被读取的"选"依赖（完全背包=同行左侧；0/1背包=左上）
   - 🔵 蓝色 = 被读取的"不选"依赖（上方 `dp[i-1][j]`）
   - 用 SVG/CSS 箭头从依赖指向当前格，让数据流向一目了然
3. **扫描方向动画**（一维表的教学灵魂）：
   - 完全背包：高亮扫描条 **从左到右** 移动（正序）
   - 0/1 背包：高亮扫描条 **从右到左** 移动（逆序）
   - 切换模式时方向反转，学生立刻看到差异
4. **公式实时显示**：顶部展示当前模式对应的递推式，正在计算的项高亮。
5. **步骤说明栏**：每步用人话解释，如"物品2(重3,值4)：j=6，正序遍历下 dp[3] 已含本物品，取 max(9, dp[3]+4=8)=9"。

## 交互功能
- **模式切换**：完全背包 ↔ 0/1 背包，切换后整张表与扫描方向、依赖箭头位置都会变化（同一数据集重算）。
- **步进控制**：上一步 / 下一步 / 播放暂停 / 重置 / 速度滑块（0.3x–3x）。
- **数据编辑**：默认预设 3 个物品（重量价值）+ 容量 5；可增删改物品行、改容量；改完自动重新计算步骤序列。
- **键盘快捷键**：← → 步进，空格播放/暂停，R 重置（提升课堂流畅度）。

## 技术实现要点
- **预计算步骤序列**：切换模式或改数据时，先把整个 DP 过程跑一遍，把每一步的快照（哪些格被读、被写、写前写后的值、说明文字）存成数组；播放时只做回放，逻辑简单、步进/跳转都稳定。
- **原生 JS + CSS**：无框架，单文件。用 CSS Grid 画表格，CSS 变量管理配色，`requestAnimationFrame` 或 `setTimeout` 做播放。
- **响应式**：宽屏左右并排，窄屏上下堆叠。
- 配色（深色现代）：背景 `#0f172a`，卡片 `#1e293b`，文字 `#e2e8f0`，紫/橙/蓝强调色如上。等宽字体显示数值与公式。
